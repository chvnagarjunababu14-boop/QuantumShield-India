# Explore

## Filters

- Search, topic, and difficulty are labeled fields in one panel.
- Results update as the fields change. The catalogue is local, so there is no remote suggestion list.
- A status message says how many sample lessons match, for example `3 sample lessons`.
- An empty search names real topics to try and offers Clear filters.

`search filter empty results` matched the empty-state guidance. A second landing query for a course catalog did not match.
