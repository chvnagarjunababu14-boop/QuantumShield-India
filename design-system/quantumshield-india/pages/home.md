# Home

Overrides `MASTER.md` for the learning homepage. The Phase 1 foundation note in `foundation.md` described a single status screen. This page keeps that live health check and adds the catalogue.

## Layout

- Masthead, then one headline with a primary action, `Explore lessons`.
- Topics are a two-column text index from 768px up, not icon tiles.
- Paths are a numbered list. Featured lessons are a single column.
- The community note and the service connection sit after the reading material.
- Body copy stays within about 62 characters. The headline uses `text-wrap: balance` and still wraps naturally.

## Search record

`editorial learning publication reading` and `education course catalog` returned no landing matches. This layout uses the existing tokens plus the verified line-length and heading-hierarchy guidance.
